# Qiyuan Zhang — Academic Homepage

This is a lightweight static academic homepage for GitHub Pages.

## Files

- `index.html` — homepage content
- `style.css` — visual design and responsive layout
- `assets/avatar.jpg` — profile photo

## Deploy on GitHub Pages

1. Rename the repository to `ainakangda.github.io`.
2. Keep `index.html` and `style.css` in the repository root.
3. Keep the portrait at `assets/avatar.jpg`.
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**.
6. Select **main** and **/(root)**.
7. Save and wait for the Pages deployment to finish.

The homepage should then be available at:

`https://ainakangda.github.io/`

## Before publishing

Replace the placeholder email, Google Scholar URL, and CV link in `index.html`.
Update publication titles/details with the final bibliographic information.
